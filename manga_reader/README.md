Manga Journal App

In the Home Screen you can keep track of different mangas you are interested in, and categorize them by Reading / Done / Wishlist

<img width="660" height="1349" alt="Android Emulator - Pixel_5_5554 6_27_2026 10_16_22 PM" src="https://github.com/user-attachments/assets/fa5bbf49-b453-4f67-969a-df25a7ebfde1" />

Click on Scan to add a new entry. Select an image from the camera or gallery with the manga cover, and the Google ML Kit will read the title of book.

<img width="660" height="1349" alt="Android Emulator - Pixel_5_5554 6_27_2026 10_17_26 PM" src="https://github.com/user-attachments/assets/a710cb78-6496-490e-b70d-ea7d430648d6" />

After scanning, you can edit the text (sometimes it wont read perfectly since manga covers have partly covered text on them).
Then, you can manually add the Volume number and additional notes about the chapter.

<img width="660" height="1349" alt="Android Emulator - Pixel_5_5554 6_27_2026 10_19_48 PM" src="https://github.com/user-attachments/assets/15f014e4-a7ed-45eb-9b82-cd1c9068ba87" />

From the home screen, you can edit existing entries where you can check the original scanned text before it was edited.
